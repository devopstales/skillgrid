# Glossary Reference

| Term | Source Glossary | Context |
| --- | --- | --- |
| Step | `docs/skillgrid/glossary/business.md` | A sequenced phase of an SDD change — the Intent's Step Blueprint defines the step folders (`01-schema`, `02-service-facade`, etc.). |
| Artifact | `docs/skillgrid/glossary/business.md` | A file persisted by an SDD phase — `intent.md`, `plan.md`, `research.md`, `tasks.md`, `acceptance.feature`, `verification.md`. |

No additional glossary terms (task, team, review, brief, inbox, agent) are defined in the project glossary — these are domain terms from the `docs/plan/04-teams-sub-agents-memory.md` design doc and should be added to `docs/skillgrid/glossary/technical.md` during sdd-design.
