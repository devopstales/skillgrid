# Agent global config paths

* Open Code
  * Agents: `~/.config/opencode/agents/`
  * Instructions: `~/.config/opencode/AGENTS.md`, `~/.claude/CLAUDE.md`
    *Add custom location: `"instructions": ["~/.cursor/rules/*.md", "~/.agents/AGENTS.md"]`
  * Skills: `~/.claude/skills/`, `~/.agents/skills/`
  * Commands: `~/.config/opencode/commands/`

* Kilo Code
  * Agents: `~/.config/kilo/agent/`
  * Instructions: `~/.config/opencode/AGENTS.md`, `~/.claude/CLAUDE.md`
    * Add custom location: `"instructions": ["~/.cursor/rules/*.md", "~/.agents/AGENTS.md"]`
  * Skills: `~/.claude/skills/`, `~/.agents/skills/`
  * Commands: `~/.config/kilo/commands/`

* Vscode
  * Instructions: `~/.claude/CLAUDE.md`, `~/.agents/AGENTS.md`
  * Skills: `~/.claude/skills/`, `~/.agents/skills/`
  * Prompts: `~/.config/Code/User/prompts/`
  * Agents: `~/.copilot/agents/`
  * Hooks: `~/.copilot/hooks`, `~/.claude/settings.json`

* Cursor
  * Agents: `~/.cursor/agents/`
  * Instructions / rules: `~/.cursor/rules/`
  * Skills: `~/.cursor/skills/`, `~/.agents/skills/`, `~/.claude/skills/`
  * Hooks: `~/.cursor/hooks.json`, `~/.cursor/hooks/`
  * MCP: `~/.cursor/mcp.json`
  * Settings: `~/.config/Cursor/User/settings.json`
  * Plugins: `~/.cursor/plugins/`
  * Extensions: `~/.cursor/extensions/`
