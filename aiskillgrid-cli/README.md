# aiskillgrid-cli

Go CLI that installs and configures AI agent tooling.

## Build

```
task build
```

## Test

```
task test-cli
```

## Usage

```
aiskillgrid-cli install --dry-run
aiskillgrid-cli sync-repo --sync-repo /extra/path
```

Validation logs are written to `~/.aiskillgrid/logs/install.log`.
