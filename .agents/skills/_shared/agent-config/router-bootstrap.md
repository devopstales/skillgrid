# Skillgrid Router Bootstrap

This project is configured with Skillgrid.

First action: read `.agents/skills/using-skillgrid/SKILL.md` (or the host's skill-load command).

Request classes: start / continue / status / review-only / bounded.

Announce: `Using skillgrid:using-skillgrid to {purpose}`.

Load hints:
- pi: `/skill:using-skillgrid` + `using-skillgrid/references/pi-tools.md`
- opencode: `skill` / `@using-skillgrid` + `using-skillgrid/references/opencode-tools.md`
- kilo: read the path
- cursor: `/using-skillgrid` or read
- omp: `/skill:using-skillgrid`
