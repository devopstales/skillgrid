Terminal Ops

The selected skillgrid dashboard design system. Dense mono console on an OLED slate canvas, one run-green accent for everything that is live or passing, an 8px rhythm, and a 12-column grid. Every value on this page is a :root custom property — port the token table into skillgrid-ui/src/index.css and the real build matches this.

how it works

One accent, three states. Run-green is the only brand hue — it carries active, ok, live, and success. Amber is the single warning hue, red is reserved for failure, and sky/violet are scope colors (user / global) used only in memory breakdowns and links. No gradients, no glass, no shadows: separation comes from hairline borders and the one-step surface elevation.
Density is the feature. 11px labels, 12–13px body, tight card padding. The layout reads like a terminal because the type is small, the grid is fine-grained, and status is encoded in color + tiny chips, not big cards.

Layout & grid

Fixed 220px sidebar + fluid 12-column content grid. Cards span by 3/4/6/8/12. Below 1100px everything stacks to full width.

Cards & KPI

A card is a one-step elevation: --surface-1 on --bg, a --line border, 6px radius, an uppercase 11px header with a hairline divider, 12px body padding.

card anatomy

Header = uppercase label (11px, .1em tracking, muted) + optional right-aligned status. Body = 12px padding. No shadow — the 1px border and surface step do the separation.
