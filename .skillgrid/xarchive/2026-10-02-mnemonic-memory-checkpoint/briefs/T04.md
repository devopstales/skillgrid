## Produce

### Route

```
POST /sessions/{id}/checkpoint/claim?project=|directory=
200 {"due": bool, "reason": ""|"below_min_events"|"cooldown"|"disabled"|"unknown_session", "prompt": string}
```

- Register next to other session routes with `requireWriteAuth`.
- Always **200** with a body — never 404 for unknown session (`due:false, reason:unknown_session`).
- `prompt` non-empty **only** when `due:true`.
- When due: call `h.Memory().ClaimCheckpoint(ctx, id, now)` **before** responding.

### Wiring

1. `s.withProjectHandle` → open handle.
2. `st, err := h.Memory().CheckpointState(ctx, id)`.
3. Resolve checkpoint config: `cfg := config.Load(".").Checkpoint` (tests Chdir into a workdir with `config.d/`; production CWD is the served project). Do **not** invent a parallel config loader.
4. `due, reason := checkpoint.Decide(st, cfg, s.now())`.
5. If not due → `{due:false, reason, prompt:""}`.
6. If due:
   - Load events since `st.LastWriteAt` (all events when zero) from `session_events` for this session — **structured fields only** (sequence, action_type, tool_name, path, command, result_status, timestamp). Map to `checkpoint.Event`. Prefer extending the existing query helpers in `toolevents.go` with a `sinceTS` filter rather than a one-off copy.
   - Existing titles: live observation titles for this session (`deleted_at IS NULL`).
   - `digest := checkpoint.BuildDigest(events, 1500)`
   - `prompt := checkpoint.RenderPrompt(...)` with `MaxObservations: cfg.MaxObservations`
   - `ClaimCheckpoint`
   - return `{due:true, reason:"", prompt}`

### Server clock

Add `now func() time.Time` on `Server`, default `time.Now` in `NewServer`. Tests override `s.now = func() time.Time { return frozen }` for cooldown / re-due cases.
