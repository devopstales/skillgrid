## Produce

### `session_inject.RenderIndex` (new)

```go
type IndexConfig struct{ Summaries, Observations, MaxTokens int }
func RenderIndex(summaries []memory.Session, observations []memory.Observation, cfg IndexConfig) string
```

- Return `""` when both inputs empty.
- Summaries first (up to cfg.Summaries): `- <short session id> <YYYY-MM-DD>: <first sentence of summary>`
- Then observations (up to cfg.Observations): pinned first, then newest — `- #<id> <type> <title> · <YYYY-MM-DD> · ~<tok>`
  - `tok` = `EstimateTokens(title)` (or title+type — stay small)
- Footer: `Full text: mem_get_observation <id> · mem_timeline <id> · mem_search <query>`
- Cap: while `EstimateTokens(output) > MaxTokens`, drop the **oldest observation line** first (then oldest summary if needed); state omitted count when dropping.
- Section header optional inside RenderIndex or left to RenderPrime — prefer RenderIndex returns body under `## Memory` **or** plain body and RenderPrime wraps. Match tests: non-empty MemoryIndex → `## Memory` appears in prime output.

### `loop.PrimeInput`

Add `MemoryIndex string`. `RenderPrime`: if non-empty after trim, append `\n## Memory\n` + index (or if index already includes `## Memory`, append as-is — pick one and test it). Empty → no section.
