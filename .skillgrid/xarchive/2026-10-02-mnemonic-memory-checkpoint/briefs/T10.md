## Produce

### `GET /sessions/{id}/events` (`http/toolevents.go`)

Additive response fields. Keep existing `events` behavior unchanged.

```json
{
  "project": "...",
  "sessionId": "...",
  "events": [ /* existing toolEvent[] */ ],
  "observations": [
    {
      "id": <int>,
      "type": "decision",
      "title": "...",
      "created_at": "RFC3339/ISO string from DB",
      "tokens": <int>,
      "pinned": <bool>
    }
  ]
}
```

- Query live observations for the session: `observations` where `session_id = id` AND `project = ?` AND `deleted_at IS NULL`.
- Order: pinned first, then newest `created_at` (same as elsewhere).
- `tokens` = `session_inject.EstimateTokens(title + " " + content)` (or title alone if content empty) — reuse the existing 4-chars≈1-token helper; do not invent a second estimator.
- Empty session / no observations → `"observations": []` (never omit the key; never 404).
- Soft-deleted observations must not appear.
