# Cross-Change Research Findings

Durable, still-relevant research findings carried forward across changes. Per-change research lives in `.skillgrid/specs/<topic>/findings.md` (archived with the change). `reflect` lifts the findings that outlive the change into this file, so they survive the archive.

**Rule:** a finding belongs here only if it constrains *future* changes — an external API fact, a version's behavior, a domain constraint, a library limitation. A finding that is only true for one change stays in that change's `findings.md`.
