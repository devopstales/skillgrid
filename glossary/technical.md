# Technical Glossary

| Term | Definition | Use When | Avoid |
| --- | --- | --- | --- |
| **Mnemonic** | skillgrid's local-first memory engine: memory + code index + web cache + graph in one SQLite store and single binary | Referring to the `internal/mnemonic` subsystem, `skillgrid mcp`/`serve`/`index` | "MemIndex" (legacy name), "Engram" (the protocol it is compatible with) |
| **Observation** | A curated memory record (What/Why/Where/Learned) stored in the `observations` table | Any memory content stored or searched by agents | "Note", "record" (unqualified) |
| **Node** | A graph entity (kind: session, observation, file, symbol, web_entry, basic_block, route, tool, shape) stored in `graph_nodes` | Graph schema, tools, and visualizer | "Vertex", "entity" (in graph context) |
| **Edge** | A typed, directed relationship between two graph nodes stored in `graph_edges`, owned by a pass | Graph schema, tools, and visualizer | "Link", "relation" (use MENTIONS/CITES/RELATED_TO edge types instead of generic "relation") |
| **Edge type vocabulary** | The single fixed set of allowed edge types, grouped by layer: core (CONTAINS, DEFINES, CALLS, IMPORTS, EXTENDS, MENTIONS, CITES, RELATED_TO, FOLLOWS_FROM), verdicts (CONFLICTS_WITH, SUPERSEDES), PDG (CFG, CDG, REACHING_DEF, SOURCE, SINK, SANITIZES, TAINTED, TAINT_PATH), contracts (HANDLES_ROUTE, FETCHES, ENTRY_POINT_OF, HANDLES_TOOL, DEFINES_ROUTE, CONSUMES_PROP) | Writing or validating edges, UI legend | Inventing new edge types without updating the vocabulary in one place |
| **Pass** | A self-contained extraction/unit with a `pass` label on its edges (synthesis, symbols, pdg, contracts, manual) that owns and regenerates only its own edges | Rebuild/incremental behavior, config gates | "Stage" in this context |
| **Auto-synthesis** | Deterministic regeneration of edges derived from existing tables (CONTAINS/MENTIONS/CITES/FOLLOWS_FROM) | Graph rebuild behavior, "rebuild" discussions | "Event sourcing" (it is not) |
| **Manual edge** | A graph edge created by an agent via `graph_slink`/`POST /graph/link` with `source=manual`, surviving auto-synthesis rebuilds | Edge lifecycle, `graph_slink` docs | "Pinned edge" |
| **Symbol** | A derived graph-owned node for a function, method, or type extracted from a Go, TypeScript, or Python source file | Symbol pipeline, `graph_context` on symbols | "Function" (unqualified — may also mean a node of kind symbol) |
| **Symbol pipeline** | The opt-in tree-sitter extraction pass inside `codeindex` that produces symbol nodes and DEFINES/CALLS/IMPORTS/EXTENDS edges across Go/TS/Python | Phase 2 tasks, config `symbols.enabled` | "GitNexus indexer" |
| **PDG** | A per-function program-dependence graph: basic-block nodes with CFG (control-flow) and CDG (data-dependence) edges, plus reaching definitions | `pdg_query`, phase 3, `pdg.enabled` | "Call graph" (PDG is intra-function dataflow, not just calls) |
| **Taint path** | A precomputed source-to-sink flow (a SOURCE marker flowing to a SINK, optionally through SANITIZES and across CALLS) stored as a TAINT_PATH edge | `explain`, `pdg.enabled` | "Data flow" (unqualified) |
| **API contract** | The extracted HTTP route / MCP-RPC tool / response-shape subgraph: route, tool, shape nodes with CONSUMES_PROP/FETCHES/HANDLES_ROUTE/HANDLES_TOOL/DEFINES_ROUTE/ENTRY_POINT_OF edges | `route_map`/`tool_map`/`shape_check`/`api_impact`, phase 4, `contracts.enabled` | "Endpoint map" |
| **Mini-Cypher** | The documented, limited Cypher subset (single-pattern MATCH with WHERE on known props, minimal RETURN/aggregate) over graph_nodes/graph_edges; full Cypher features are rejected with a structured error | `cypher` tool | "Cypher" (unqualified — implies full language support) |
| **Blast radius** | The set of nodes reachable from one node along edge directions (GitNexus "impact"), returned with hop distances | `graph_impact` tool, impact discussions | "Downstream impact" (use direction parameter instead) |
| **Rename planner** | A read-only report of all affected locations for a symbol (call sites, CALLS edges, MENTIONS files), ranked, without mutation | `rename` tool | "Rename" (unqualified — no files are edited) |
| **Verdict** | A stored relationship judgment between two observations (related, compatible, scoped, conflicts_with, supersedes) as a typed edge with confidence/reason; `not_conflict` deletes the edge | `graph_judge`, verdicts edge group | "Conflict" (unqualified) |
| **Trace** | Shortest directed path between two nodes over an allowed edge-type set (GitNexus "trace") | `graph_trace` tool | "Path" (use for the result, trace for the operation) |
| **Subgraph extraction** | One round-trip fetch of `{nodes, edges}` JSON for the visualizer, anchored optionally at a node | `/graph/subgraph`, Sigma rendering | "Graph snapshot", "export" |
| **OCBI convention** | MCP tool output is raw JSON only, no leading prose (validated by `ValidateRawJSON`) | Writing MCP handlers and tool output tests | "JSON responses" (unqualified) |
| **Truncated traversal** | Traversal result flag set when depth or node caps cut the walk short | Traversal error semantics, cap tuning | "Timeout" |
