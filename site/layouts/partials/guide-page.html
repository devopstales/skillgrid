Workflow guide

Every skill, and one idea followed to shipped.

A set of skills that take a change from a rough idea to shipped, tested and documented code, one skill per stage. The important state lives in files in your repository, not in a chat, so the work survives across sessions and is shared with your whole team.

The 32 skills

There are 32. You run only the ones a change needs, in whatever order fits. The four verbs (interview → blueprint → slice → verify) are the spine; the rest are the capabilities each verb loads at the right moment.

Skill reference

One entry per skill: what it does, what it writes, and what group it belongs to. Every entry is self-contained, so you can jump straight to the one you need.

The files that carry the work

Everything the workflow knows is written into files in your repo. A chat can end, a session can be cleared, a teammate can pull the branch, and the knowledge is still there because it was never trapped in a conversation. The full map of what lives where, and who owns each file, is in the files and ownership table on the skills page.

The key idea is that these files nest. One at the root for rules that apply everywhere; more inside .skillgrid/specs/<date>-<topic>/ for the change's own artifacts. When a skill works on a change, it reads the nearest one, so it sees both the project-wide conventions and the local ones. onboarding creates them, every other skill reads them, and ship's Reconcile step keeps them current.

Rigor tiers — match effort to risk

T0–T3 are a per-change verification dial. The project default is set at onboarding and a Tier: line in the briefing overrides it. The tier selects which tail steps run; the change's shape still sets a floor the tier can't lower. Skipped steps are recorded as skipped, never silently absent.

Build shapes

How the work is ordered — which behavior exists first — is a recorded decision, not a vibe. The blueprint header carries Build shape: (tracer thread / smallest usable whole / facade / journey); slicing reads it to order the first wave.
