Limits

What it will not do.

The limits matter as much as the features.

Will not

Mark a feature done on its own

Built is not done. Done waits for the QA gate to pass and for tests to be in.

Will not

Invent a decision you have not made

The Owed-Decision Gate catches it mechanically. Override it and the guess is recorded as an Assumed blueprint, flagged until Ratify confirms it.

Will not

Lower the floor the change's shape demands

A T0 that is actually a migration still gets the migration's L3 floor. The tier changes the default, never the minimum.

Will not

Edit your code during review

The review reads and reports, sorted worst-first. You decide what to change.

Will not

Rewrite another skill's files

Ownership is fixed, which is what keeps them trustworthy over time.
